**«У нас есть приложение, готовое на 90%. Нужна помощь с исправлением последних ошибок.»** Эти последние 10% — это 95% работы. Этот инструмент делает эту работу.

---

## Что это такое

Last Mile 360 — это единый инструмент, который берёт любое интуитивно написанное приложение и делает его безопасным для продакшена. Он сканирует, оценивает, исправляет и непрерывно мониторит кодовые базы по пяти измерениям: **безопасность, безопасность базы данных, инфраструктура, наблюдаемость и качество кода**.

Он объединяет лучшие возможности 15+ open-source фреймворков агентов, движков инференса, систем памяти и инструментов компьютерного использования в одну безопасную платформу, нативную для Cloudflare, без самостоятельно размещённой инфраструктуры.

**Чем это не является:** Не исправляет product-market fit. Не перепроектирует UX. Не оптимизирует бизнес-логику. Делает ваш код безопасным для реальных пользователей с реальными данными.

## Быстрый старт (появится в Фазе 1)

CLI находится в активной разработке. Когда Фаза 1 будет выпущена:

```bash
npm install -g @last-mile/cli
last-mile login
cd your-vibe-coded-app
last-mile scan       # Сканировать безопасность, БД, инфру, наблюдаемость, качество
last-mile score      # Посмотреть оценку готовности к продакшену (0-100)
last-mile fix        # Автоисправить что можно через PR
last-mile monitor    # Включить непрерывный мониторинг
```

### Разработка (участвуйте сейчас)

```bash
git clone https://github.com/itallstartedwithaidea/last-mile.git
cd last-mile
npm install
npm run dev
```

Полные инструкции по настройке см. в [CONTRIBUTING.md](CONTRIBUTING.md).

| --- | --- | --- | --- |

## Пять подразделений агентов

### Подразделение 1: Агент безопасности

| Суб-агент | Инструмент | Что делает |
| --- | --- | --- |
| Сканер секретов | Gitleaks + Trufflehog | Pre-commit + полный скан репо на захардкоженные секреты |
| Аудит зависимостей | Socket.dev + OSV-Scanner + Snyk | Обнаружение атак на цепочку поставок, CVE-сканирование npm/pip/Go/Rust |
| SAST | Semgrep | Собственный движок правил для SQL-инъекций, XSS, обхода аутентификации |
| Валидатор аутентификации | OWASP ZAP | Автоматизированное тестирование на проникновение |
| Безопасность инфры | Checkov + Trivy | Неправильная конфигурация Terraform/Docker/K8s + сканирование уязвимостей контейнеров |

### Подразделение 2: Агент базы данных

**Критическое правило:** Агент БД НИКОГДА не выполняет миграции автоматически. Он генерирует файлы миграций и PR. Человек должен проверить и одобрить каждое изменение схемы.

### Подразделение 3: Агент инфраструктуры

Генерирует Dockerfile, CI/CD-воркфлоу, конфиги деплоя и управление env — только конфигурационные файлы, никогда не выполняет.

### Подразделение 4: Агент наблюдаемости

Заменяет `console.log` структурированным логированием, внедряет SDK OpenTelemetry, отслеживание ошибок Sentry, генерирует эндпоинты `/health` + `/ready`.

### Подразделение 5: Агент качества

Генерирует тестовые наборы, находит мёртвый код (knip), обнаруживает циклические зависимости (Madge), рассчитывает оценки готовности к продакшену.

## Рубрика оценки

| Категория | Вес | Примеры контрольных точек |
| --- | --- | --- |
| Безопасность | 35% | Захардкоженные секреты (CWE-798), SQL-инъекция (CWE-89), отсутствие аутентификации (CWE-306), XSS (CWE-79) |
| База данных | 20% | Нет истории миграций, нет конфига бэкапов, отсутствующие индексы, RLS отключён |
| Инфраструктура | 20% | Нет Dockerfile, нет CI/CD, секреты в закоммиченном .env, нет health check |
| Наблюдаемость | 12,5% | Нет отслеживания ошибок, только console.log, нет health-эндпоинтов, нет метрик |
| Качество | 12,5% | Нет тестов, высокая цикломатическая сложность, мёртвый код > 20%, циклические зависимости |

### Оценки

| Балл | Оценка | Значение |
| --- | --- | --- |
| 0–25 | F — Критично | Не безопасно для продакшена. Активные уязвимости безопасности. |
| 26–50 | D — Опасно | Серьёзные пробелы. Базовые вещи есть, но критические проблемы остаются. |
| 51–70 | C — Осторожно | На пути. Базовая безопасность решена, нужен мониторинг + тесты. |
| 71–85 | B — Готово к продакшену | Безопасно для продакшена. Все критические находки устранены. |
| 86–95 | A — Укреплённо | Корпоративный уровень. Полное покрытие, непрерывный мониторинг. |
| 96–100 | A+ — Уровень Norton | Лучший в классе. Все контрольные точки зелёные, полный мониторинг активен. |
